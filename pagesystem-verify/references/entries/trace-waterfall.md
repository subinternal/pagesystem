# Trace waterfall (trace-waterfall)

Kind: component. Follow one agent run on a shared timeline: nested steps, their timing and cost, and the detail of any span.

Task: See where an agent run spent its time and money, find the step that failed and inspect what it did.

Elements: [text](text.md), [input](input.md), [badge](badge.md).

Category: agent.

Native behavior: trace-waterfall. It needs pagesystem.js (see ../implementation.md).

## content

- A clearly labeled sample run
- Run totals: duration, cost, tokens, model calls, tool calls and errors
- Each span's name, target, nesting, start and duration on one time axis
- A detail card under the chosen span: status, its place within its parent, start, end, cost, tokens, a time or token breakdown and the span's own attributes
- The run's cost against the previous run

## states

- expanded
- collapsed agent
- selected span
- failed span
- failed run
- filtered
- no matching steps
- replaying: every step listed from the start, muted until the playhead reaches it; its bar draws and its card shows only once it has run

## responsive

- On a wide panel steps and bars share a row with a fixed label column; under 36rem each bar moves beneath its label on the same scale.
- Duration labels sit after a bar, before it when there is no room, and drop the cost when neither side fits.
- Run totals wrap from six columns to two rows of three.

## checks

- Bars are positioned from each span's start and duration against one axis shared by every row.
- The tree is a single tab stop: arrows move, Right expands or enters a step, Left collapses or returns to the parent, Home and End jump, Enter and Space open or fold the chosen span's detail, Escape folds it.
- Choosing a span opens its detail card beneath that row, choosing it again folds it, and the row's accessible name stays its own label; a failed span reads as failed in text, with its reason and any recovering attempt.
- A collapsed agent still marks its steps inside its own bar.
- Filtering keeps the ancestors of every match and shows a message when nothing matches.
- Run totals are derived from the spans, never typed separately.
- Hovering or focusing a bar pins a tip with its name, duration and cost; with a span open, other spans step back to context.
- Steps are drawn on the ink levels by kind (model call in full ink, tool call and agent span lighter); the only hue is the danger color of a failure.
