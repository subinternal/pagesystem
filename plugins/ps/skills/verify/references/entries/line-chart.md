# Line chart (line-chart)

Kind: component. One to four series over time, each named at its latest value, with a locator that reads any period exactly.

Task: See how a measure moved over a period, compare it with related series or the previous period, and read the exact value on any day.

Elements: [text](text.md), [separator](separator.md).

Category: data.

Native behavior: line-chart. It needs pagesystem.js (see ../implementation.md).

## content

- A headline for the inspected period: the date, the primary series' value in tabular numerals and a delta pill against the previous period or the first period, with arrow and sign
- One to four series drawn as flat lines on one value scale whose top is a round value at or above the largest datum, the unit stated once on the top value
- A low-strength area of the primary series' own color under its line; a previous-period comparison dashed in the muted ink
- A direct label at the end of each line with the series name and latest value; no detached legend
- Date labels qualified with their month first, then terse, thinned by the space available, with the inspected date in ink
- Optional dated annotations marked on the plot as a dashed line with a short flag, and written out in full beneath it
- A data table in a View data disclosure that holds every value the plot draws
- Peak and average for the primary series in the footer, and a visible sample label

## states

- latest period inspected
- period inspected by pointer
- period inspected by keyboard
- comparison with the previous period
- annotated
- narrow: key above the plot and readout in place of the tip
- reduced motion

## responsive

- From 34rem of component width each line ends in its own label in a gutter after the plot and the pinned tip follows the locator.
- Below 34rem the end labels become a key above the plot that draws each line as the plot does, the tip is hidden and the readout beneath the plot becomes visible.
- The plot redraws to its measured width: date labels thin to about one per 64px and the value scale keeps about one gridline per 48px of height.
- The value gutter grows with the text size, so scale labels never collide at 200% text.

## checks

- Every drawn value, the headline, the end labels, peak and average are read from the data table's data-value cells, never typed separately.
- The plot is a labeled image that takes focus: Left and Right step one period, Home and End jump to the first and last; pointer movement inspects the nearest period.
- The locator line, one dot per series, the pinned inverse tip and the headline all follow the inspected period; a polite live readout restates every series' value and the change.
- The tip is hidden from assistive technology; the readout and table carry the same values.
- A delta states its direction with an arrow and a signed figure, never by color alone.
- A missing value lifts the line rather than bridging the gap, and the scale starts at zero with the baseline drawn.
- Pointer moves ease in at most 90ms; keyboard steps, resizes and reduced motion move instantly.
- Re-initializing a chart replaces its drawing instead of duplicating it, and disposal disconnects its resize observer and listeners.
