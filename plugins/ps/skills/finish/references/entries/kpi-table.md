# KPI table (kpi-table)

Kind: component. A reporting table of metrics: current and previous values, a derived change, a sparkline and a status against target.

Task: Review many metrics at once, see which moved and which are off target, and reorder them to find the outliers.

Elements: [text](text.md), [button](button.md), [badge](badge.md).

Category: data.

Native behavior: kpi-table. It needs pagesystem.js (see ../implementation.md).

## content

- A clearly labeled sample with the periods compared
- A header summary counting metrics on track, at risk and off track
- Each metric's name, current value, previous value, change pill, trend sparkline and status
- Optional group headings with a subtotal row per group
- Optional target column, a unit meter of attainment and a dashed target line in each sparkline

## states

- authored order
- sorted by metric
- sorted by change
- sorted by status
- scrolled sideways with the metric column pinned
- grouped with subtotals
- compact

## responsive

- The table grows with its rows and never scrolls vertically; it scrolls only sideways when narrow.
- The metric column stays pinned while scrolling and casts a hairline edge only while rows are beneath it.
- Under 36rem metric names wrap within the pinned column so the figures keep the width.

## checks

- Number columns are right-aligned in tabular figures; the current value is set in medium weight and the previous in muted ink.
- Change is derived from current and previous; its arrow and sign read the direction and its color reads good or bad for that metric, so a falling churn is good.
- Status is derived from the target (reached, within 5%, or further), never typed; lower-is-better metrics invert the ratio.
- Subtotals are summed from their group's rows, period by period, including the sparkline.
- Metric, change and status sort through header buttons; exactly one header carries aria-sort, a second press reverses, and grouped tables sort within each group with the subtotal kept last.
- Columns whose rows mix units (current and previous values) are not sortable.
- Each sparkline is a labeled image naming its period and direction; its last value is marked.
- Sorting by pointer moves rows in at most 220ms; keyboard sorting and reduced motion move them at once, and a polite status announces the order.
