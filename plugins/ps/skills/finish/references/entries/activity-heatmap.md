# Activity calendar (activity-heatmap)

Kind: component. A daily activity grid with category filtering and date inspection.

Task: Find active days and inspect their contribution categories.

Elements: [text](text.md), [button](button.md), [input](input.md), [badge](badge.md).

Category: data.

Native behavior: activity-heatmap. It needs pagesystem.js (see ../implementation.md).

## content

- Clearly labeled synthetic data
- Selected scope and period
- Exact values and explanatory labels
- A sequential key with the range of contributions per step
- Active days and the busiest day as headline figures

## states

- all categories
- single category
- selected date
- zero activity

## responsive

- Controls wrap without reducing editable text size.
- Plots remain supplementary to native inspection controls and exact values.
- Data tables scroll in a named local region.

## checks

- Arrow keys move by day or week; Home and End reach the bounds.
- One grid cell participates in the tab order.
- Category counts partition the total and zero days remain inspectable.
- Months are named once; the selected day gets a ring and a pinned tip.
